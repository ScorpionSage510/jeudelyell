# Extension Chrome - Aide pour le Défi Géologique de Lyell

Cette extension pour Google Chrome est conçue pour vous assister lors de votre partie du [Défi géologique de Lyell](https://www.pedagogie.ac-nice.fr/svt/productions/defi-lyell/). Elle ajoute plusieurs fonctionnalités pour faciliter le jeu ou analyser les réponses.

## Fonctionnalités

*   **Mode Invincible ("True") :** Activez un mode où vous ne pouvez pas perdre (utile pour tester ou apprendre sans pression).
*   **Affichage de la Réponse (avec délai) :** Révélez la disposition correcte après un certain temps, vous permettant d'essayer d'abord puis de vérifier.
*   **Comparateur Visuel :** Compare votre proposition avec la solution et met en évidence les éléments mal placés en rouge pour une identification rapide des erreurs.

## Installation

Pour installer et utiliser cette extension :

1.  **Téléchargez le code :**
    *   Cliquez sur le bouton vert `<> Code` en haut de cette page GitHub.
    *   Sélectionnez "Download ZIP".
2.  **Extrayez l'archive :**
    *   Décompressez le fichier `.zip` que vous venez de télécharger dans un dossier sur votre ordinateur. Retenez l'emplacement de ce dossier.
3.  **Ouvrez les extensions Chrome :**
    *   Ouvrez Google Chrome.
    *   Tapez `chrome://extensions` dans la barre d'adresse et appuyez sur `Entrée`.
4.  **Activez le Mode Développeur :**
    *   En haut à droite de la page des extensions, assurez-vous que l'interrupteur **"Mode développeur"** est activé (bleu).
5.  **Chargez l'extension :**
    *   Cliquez sur le bouton **"Charger l'extension non empaquetée"** (qui apparaît lorsque le mode développeur est activé).
    *   Une fenêtre de sélection de dossier s'ouvre. Naviguez jusqu'au dossier que vous avez **extrait à l'étape 2** et sélectionnez-le (le dossier contenant des fichiers comme `manifest.json`, etc.). Cliquez sur "Sélectionner un dossier".
6.  **Vérification :**
    *   L'extension "Défi Lyell" devrait maintenant apparaître dans votre liste d'extensions et être active. Vous devriez voir son icône près de votre barre d'adresse.
